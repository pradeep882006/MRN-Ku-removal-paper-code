# MRN-Ku-removal-paper-code
Zipped files are labeled with appropriate experimental condition. They contain collated data in one or multiple .pkl files for that specific condition.
"ScriptForDataExtractionAndPlotting_KuRemovalPaper.py" is script for plotting background corrected of fluorescence intensity traces, survival probability curves and calculating lifetimes of molecules.
Detailed instructions to run the code and expected results (screenshots) are provided in the document titled "InstructionsToRunCode".
